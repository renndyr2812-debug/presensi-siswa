🔗 Cara Menghubungkan ke Akun Google Anda:
  1. Buka Google Spreadsheet Baru di akun Google Anda.
  2. Klik menu Ekstensi > Apps Script.
  3. Hapus kode bawaan, lalu paste kode dari file google-apps-script.gs ().
  4. Klik tombol Terapkan (Deploy) > Deployment Baru > Pilih Jenis: Aplikasi Web (Akses: Siapa saja) > Klik Terapkan.
